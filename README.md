# Seventeen Syllables of Debugging

A haiku about debugging, in the 5-7-5 shape:

> Cursor blinks at three
> a stack trace scrolls past midnight
> the bug was one char

`main.py` (pure Python standard library) writes the haiku to `$MAKEFUN_OUTPUT_DIR/entry.txt`. The output is byte-identical on every run.
